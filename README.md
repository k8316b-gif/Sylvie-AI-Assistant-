# Sylvie AI Assistant

**Sylvie AI Assistant** is an open-source, customizable, JARVIS-inspired agentic AI companion designed to automate everyday tasks and multi-step workflows from simple user commands.

## Vision
Most AI assistants today are either passive chatbots or locked behind expensive monthly subscriptions. Sylvie aims to bridge this gap by offering a practical, agentic workflow engine powered by a flexible API-tier model—allowing users to start with free API tiers for daily tasks and seamlessly top up or switch to paid tiers only when needed.

## Planned Core Features
- **Agentic Workflow Engine:** Execute complex, multi-step tasks from natural language commands.
- **Flexible API-Tier Management:** Support for free and paid API tiers without heavy recurring software subscriptions.
- **Modular & Customizable:** Built to be open-source so users and developers can extend workflows and tailor Sylvie to their daily routines or freelance tasks.

## Status
Currently in active architecture and early development by a core team of 2–3 builders. Initial MVP codebase coming soon.
